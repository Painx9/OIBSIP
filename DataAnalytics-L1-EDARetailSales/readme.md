# Retail Sales Exploratory Data Analysis (EDA)

## Project Overview

This project is part of the Oasis Infobyte Data Analytics Internship (Level 1 - Task 1). The objective is to perform a thorough Exploratory Data Analysis (EDA) on a retail sales dataset to uncover patterns, customer behavior trends, and actionable business insights.

## Tech Stack

- **Language:** Python
- **Libraries:** pandas, numpy, matplotlib, seaborn, scikit-learn
- **Environment:** Jupyter Notebook (VS Code)

## Features & Analysis

- **Data Cleaning & Inspection:** Verified zero null values and corrected datetime data types.
- **Time Series Analysis:** Visualized monthly and quarterly sales trends using line charts to identify seasonal peaks (e.g., strong Q2 and Q4 performance).
- **Customer Demographics:** Analyzed the distribution of customer age groups (18-64) and the gender breakdown using histograms and count plots.
- **Product Category Performance:** Compared total revenue versus total quantity sold across Electronics, Clothing, and Beauty categories.
- **Correlation Analysis:** Generated a heatmap to map relationships between numerical variables, highlighting the strong correlation between Price per Unit and Total Amount.
- **Business Recommendations:** Concluded with 3 specific, actionable business recommendations based on the data findings.
